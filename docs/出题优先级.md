# 出题优先级规则（exmsys-dev）

> 适用模块：巩固练习 / 专项训练 / 模拟考试 / 错题本 / 助记助学
> 核心实现：`utils/data_manager.py:765` 的 `_priority_sample`（统一底层）+ `extract_questions*`（顶层入口）
> 数据来源：题目答题统计 `question_stats`（correct_count / wrong_count / last_correct / retention_due / unstable / confidence）

---

## 一、核心算法：`_priority_sample`（所有模块共用）

按优先级从题目列表中抽 `count` 道，分两步排序。

### 1.1 第一层：4 大组（group）

| group | 判定条件 | 含义 | 优先级 |
|-------|---------|------|-------|
| **0** | `wrong_count > 0` 且 `wrong_count >= correct_count` | 错题本里的题 | 🥇 最高 |
| **1** | `correct_count == 0` 且 `wrong_count == 0` | 从未答过的新题 | 🥈 次高 |
| **2** | `correct_count == 1` 且 `wrong_count == 0` | 仅答对 1 次（"猜对防护"） | 🥉 第三 |
| **3** | 其余 | 答对 ≥ 2 次，或答对答错都有的题 | 最后 |

> **设计意图**：错题本 > 新题（覆盖盲区）> 猜对题（可能是蒙的）> 其它。

### 1.2 第二层：Group 3 内部子排序（sub）

只有落在 Group 3（"其余"）时才进一步细分子组：

| sub | 条件 | 含义 |
|-----|------|------|
| **0** | `retention_due = True` | 遗忘预警（距上次答对 ≥ `retention_days_threshold` 天） |
| **1** | `unstable = True` | 不稳定（消退型 / 波动型 / 全错） |
| **2** | `last_correct == False` | 上次答错（但已对多过错，未入错题本） |
| **3** | 其余 | 普通已掌握题 |

### 1.3 第三层：同级内部细排序（保证稳定可复现）

按以下元组升序（`sort(key=lambda x: (group, sub, accuracy, total_ans, -wrong, random))`）：

1. **group** 升序
2. **sub** 升序
3. **正确率** `accuracy = correct/(correct+wrong)` 升序（低正确率优先）
4. **总答题次数** 升序（少见的优先）
5. **-wrong_count** 升序（等价 wrong 降序）
6. **random.random()** 升序（最终打破平局，避免每次完全相同）

## 二、各模块的差异化抽题策略

### 2.1 巩固练习（`_generate_consol_questions`，pages/consolidation.py:52）

不调用 `_priority_sample`，而是基于 `get_mastery_distribution` 的两套列表**手动编排 4 级优先级**：

| 优先级 | 来源 | 排序依据 |
|-------|------|---------|
| 1 | 消退型（unstable_type == "消退型"） | 答对过又答错，最需关注 |
| 2 | 遗忘预警（retention_list） | `days_since_correct` 降序（越久未答对越靠前） |
| 3 | 波动型（unstable_type == "波动型"） | 对错交替，掌握不稳定 |
| 4 | 不确定题目（self_uncertainty > 0） | `uncertainty_score` 降序（标记次数越多越靠前） |

> 取最多 **`consol_per_round` 题**（系统设置可配，**默认 60**，范围 10~200；2026-09-30 前写死 60），
> 逐个去重（同一题只出现一次），并打 `_tag` 标记（消退型/遗忘预警/波动型/不确定题目）供答题页用颜色区分。
> 题池不足时按实际数量出题，不报错。
>
> **只配总题数**（区别于专项/综合的"各题型题数"）：题源是不稳固题目，
> 先按 4 级优先级选、再按题型排序显示，**各题型数量由题库实况决定**，无法按题型配额。
>
> **题型顺序（2026-09-29 用户要求）**：选出题目后，再按**稳定排序**把题型归组为
> **单选 → 多选 → 判断 → 案例题**（`_TYPE_ORDER`），**不使用随机题型顺序**。
> 稳定排序保证**同类题内部的优先级次序不变**（仍是 消退型 > 遗忘预警 > 波动型 > 不确定题目）——
> 即"先按优先级选 `consol_per_round` 题，再按题型排显示顺序"。
> 修复前该顺序是按优先级串联、题型交错（实测三级前几题为 judge, 案例题, 案例题, multi, multi, judge, …）。
>
> **答案展开状态（2026-09-29）**：巩固练习题池两轮之间高度重叠（实测 **60/60 完全相同**），
> 故进入新一轮前必须清空上一轮的 `consol_show_ans_{qid}` 展开状态，
> 否则抽到上一轮做过的题时答案会默认展开。由 `_clear_consol_show_ans()` 承担，
> 在 `_generate_consol_questions()`（开始新一轮）与 `_resume_consol_draft()`（恢复草稿）两处调用。

### 2.2 专项训练（`extract_questions_by_category`，utils/data_manager.py）

- 先按 `category` 严格过滤
- 再按 单选/多选/判断 分组
- **每组内部走 `_priority_sample`**（错题 > 新题 > 猜对 > 其它）
- 默认配额：单选 30 / 多选 20 / 判断 10
- 题型块按 单选 → 多选 → 判断 顺序输出（案例题不参与）
- **知识板块专项训练不出案例题（v2.8 用户明确）**：抽题入口一律传 `case_count=0`，
  即使板块内混有案例子题（如四级的"异常心理学"含 1 道案例子题）也**不带出**。
  案例题只在「综合训练」中出现。

### 2.3 综合训练（`extract_questions` + `extract_case_questions`，pages/specialized.py）

- 主卷走 `extract_questions`（单选/多选/判断，配置 `comp_single/multi/judge_count`）
- **案例题单独抽取**：`extract_questions(..., indefinite_count=0)` 先把案例题排除，
  再由**复选框开关 `comp_case_enabled`（默认 False）**决定是否
  `extract_case_questions(comp_case_count, exam_type, questions)` 追加卷末
  （原因：`extract_questions` 的 `indefinite_count` 是**按题**抽，会把同一案例的子题
  拆散；按案例单位抽才能保证背景完整）
- 开关 `comp_case_enabled = False`（默认）时不出案例题；勾选后按 `comp_case_count`
  （**默认 1**）抽案例——该值是**案例「个数」**，抽 N 个案例即带出这 N 个案例的**全部子题**，
  **实际出题数 = 抽到的案例所包含的子题数**（依题库实际情况，**子题数不设限**）；
  案例数超出题库实际案例数时按实际数量封顶，不报错
- 抽出的案例子题**先按案例分组**，再追加到卷末（保证背景与子题相邻且顺序稳定）

### 2.4 模拟考试（`MOCK_EXAM_CONFIG` + `extract_questions_by_super`）

- 按 `SUPER_CATEGORY_MAP` 把题目映射到超类（心理学综合 / 咨询实务）
- **关键差异**：用 `_balanced_sample_by_type`（utils/data_manager.py）**均匀分配到各子板块**，避免大板块挤压小板块
  - 每板块配额 = `total_count // n`，前 `total_count % n` 个板块多 1 道
  - 配额未用完时，从所有板块剩余题里**按 `_priority_sample` 补齐**
- 每个子板块内部仍走 `_priority_sample`（错题 > 新题 > ...）
- 出题配置**直接读内置 `MOCK_EXAM_CONFIG`**（v2.8：系统配置不再暴露模拟考）：
  - 该科有固定的真实试卷模型（心理学综合 150/50/50、咨询实务 140/60/0+10 案例、
    初级 200/100/0），时长与分值**始终固定**
  - `get_mock_exam_config()` 已于 v2.8 移除；如需调整请直接改 `MOCK_EXAM_CONFIG`
- **模拟考案例题口径与综合训练不同**：按**子题数量**凑够 `cfg["indefinite_count"]`
  （如咨询实务 10 道案例小题），按案例为单位随机选取、`cases` 过滤掉无子题的脏记录，
  不再写死 `subject_key == "counseling"`。
  （综合训练是"按案例**个数**"，两者刻意区分：模拟考模拟真实试卷的题数结构）

### 2.5 错题本（`get_top_wrong_questions`，utils/data_manager.py → data_access.py）

不走 `_priority_sample`，直接 SQL 层 `ORDER BY` 排序：

```sql
ORDER BY (COALESCE(s.wrong_count, 0) - COALESCE(s.correct_count, 0)) DESC
LIMIT ?
```

- **排序键**：净错数 = `wrong_count - correct_count`（错远多于对的排最前）
- 默认取 50 道
- 过滤 `exam_type`（按当前题库）

> 设计意图：错题本只关心「错多对少」的题，不需要新题和"猜对防护"逻辑。

### 2.5 助记助学（数字题 / 人名题 / 量表题 / 不确定题）

不走 `_priority_sample`，是**筛选**而非抽题：
- 数字题：题干含数字关键词 + 选项含数字 + 答案含数字（三步过滤），按类型（条目/月龄/岁数/病程/其他）分组
  - **数字判定（v2.8.3 收窄）**：`_has_number()` 只认**阿拉伯数字**或中文**数量结构**
    （数词+量词 / 第X / X分之X）；孤立的中文数词不算 —— 排除"一致 / 一方 / 统一 / 一般 /
    同一性 / 逐次 / 多项"这类合成词误判
  - **案例背景题排除（v2.8.3）**：`_is_case_background()` —— 题干开头是
    「求助者 / 来访者 / N岁男女性」人物背景叙述的题直接不收录（年龄只是背景，非知识点）
  - 判断题特例保留：题干含 N岁 / N月龄、答案为"正确/错误"的判定题照常收录
- 人名题：人名关键词 + 排除判断题 + 概念后缀词
- 量表维度题：题干含「量表 / 维度」关键词
- 不确定题：`self_uncertainty > 0`，按 `uncertainty_score` 降序

## 三、判定字段怎么算出来的

| 字段 | 来源 | 写入时机 |
|------|------|---------|
| `correct_count` / `wrong_count` | `question_stats` 表 | 每次 `append_answer_record` 时累加 |
| `last_correct` | `question_stats` 表 | 答题时更新 |
| `retention_due` | **动态计算**（`get_mastery_distribution`） | 读取时算（不落库），`days_since_correct >= retention_days_threshold` |
| `unstable` | **动态计算**（`get_mastery_distribution`） | 读取时算，基于 `answer_history` 切换次数 |
| `confidence` | `question_stats.confidence` | `batch_update` 预计算并写入 |
| `mastery_level` | `question_stats.mastery_level` | `batch_update` 预计算（0~5） |
| `self_uncertainty` | `question_stats.self_uncertainty` | 用户主动标记"不确定"时 +1 |
| `wrong_count >= correct_count` | 判定写入错题本 | 每次答题后自动 |

`unstable_type` 三种状态判定（utils/data_manager.py:1260-1265）：
- **全错**：`not any(history)`（从没错过）
- **消退型**：`not history[-1] and changes < 2`（最近一次答错，且切换次数 < 2）
- **波动型**：其余（对错交替，最近可能对也可能错）

## 四、关键设计权衡

1. **错题本里但已答对多次（wrong < correct）会自动出组**：会自动从 Group 0 降级到 Group 3，意思是答对的次数多了就降低优先级。
2. **"猜对防护" Group 2**：仅答对 1 次且从未答错的题，会优先于"多次答对"题组，避免用户只看到自己已掌握的题。
3. **同优先级内 random.random() 打破平局**：避免每次抽题完全相同，但保证相同条件下分布基本稳定。
4. **模拟考试的"板块均匀分配"**：避免心理学综合里"咨询心理学"200 题挤压"测量与评估"50 题；保证小板块也能被覆盖。
5. **巩固练习 4 级优先级 vs 错题本只关心净错数**：巩固练习的目标是"补盲 + 防遗忘"，所以新维度（消退/遗忘/波动/不确定）比单纯错题本更全面。
