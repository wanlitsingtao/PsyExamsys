# 第一部分：需求说明书

## 1. 项目概述

### 1.1 项目背景
题库文件位于 `E:\LingMa\exmsys\exmbase` 目录下，包含11个docx格式的考题文件，覆盖心理咨询师考试的基础理论和咨询实务两大模块，含单选题、多选题、判断题、不定项选择题四种题型，总计1878道题目。需要基于这些题目构建一个功能完整的背题系统。

### 1.2 项目目标
开发一套包含**首页（数据统计）、专项训练、模拟考试、巩固练习、错题本、配置管理**六大模块的心理咨询师考试辅助学习系统，帮助用户高效备考。

### 1.3 用户角色
- **普通用户（考生）**：使用所有学习功能
- **管理员**：使用配置管理模块进行题库管理和系统参数配置

### 2.2 首页（数据统计）模块

#### 2.2.1 功能描述
系统默认首页，采用四维 Tab 面板展示用户学习全貌。Tab 顺序：错题统计 → 知识掌握情况分析 → 答题统计 → 考试记录。所有数据采用 session_state 缓存机制，仅在数据版本变化时重新加载，确保页面秒开。

#### 2.2.2 四个统计维度

| Tab标签 | 内容 |
|---------|------|
| 📕 错题统计 | 错题总数、最高答错次数、错题占比、知识板块错题分布（含错题比率：错题数/板块总题数×100%）、高频错题TOP 20 |

| 📝 答题统计 | 总答题次数、正确率、各模式统计（专项/模拟/错题本/巩固）、各板块答题统计、最近50条答题记录 |
| 📋 考试记录 | 模拟考试记录（按会话分组显示两科成绩、正确率、用时） |

#### 2.3.3 交互逻辑

1. **开始训练**：选择综合训练或指定知识板块，系统按优先级抽题算法抽取60题（30单选+20多选+10判断），按单选→多选→判断顺序排列
2. **答题过程**：
   - 可任意切换题目（上一题/下一题/答题卡点击跳转）
   - 答题卡使用 Streamlit 原生 `st.button` 网格（支持颜色标记和导航）
   - 随时点击"查看答案"展开/收起正确答案和解析
   - 显示该题历史答题统计和上次答题结果标记
3. **提交答案**：
   - 点击"提交全部答案"，使用批量操作一次性评分并更新数据
   - 多选题和不定项选择题：必须完全匹配才得分（漏选、多选均不得分）
   - 未答题目按错误处理
4. **成绩计算**：
   - 单选题每题1分，多选题每题1.5分，判断题每题0.5分
   - 满分为 30×1.0 + 20×1.5 + 10×0.5 = 65分
5. **结果记录**（批量写入，减少I/O）：
   - 答错题自动加入错题库（遵循错题统计规则）
   - 答对题从错题库移除（如符合移除条件）
   - 更新每题累计答对/答错次数统计（question_stats.json）
   - 追加答题过程记录（answer_records.json）

### 2.4 模拟考试系统模块

#### 2.4.1 功能描述
模拟真实考试环境，采用**固定两科结构**（不可配置）：

| 科目 | 时间 | 单选题 | 多选题 | 判断题 | 不定项选择题 | 满分 |
|------|------|--------|--------|--------|-------------|------|
| 心理学综合 | 120分钟 | 150题(0.4分/题) | 50题(0.6分/题) | 50题(0.2分/题) | 0题 | 100分 |
| 咨询实务 | 120分钟 | 140题(0.4分/题) | 60题(0.6分/题) | 0题 | 10题(0.8分/题) | 100分 |

两科按顺序依次进行（心理学综合→咨询实务），每科独立计时。题目从对应超类的知识板块中通过均衡采样算法抽取，确保各子板块均匀分配配额。

#### 2.4.2 交互逻辑

1. **开始考试**：点击"开始模拟考试"→确认弹窗→开始计时→进入心理学综合科目
2. **答题过程**：
   - 可任意切换题目（上一题/下一题/答题卡点击跳转）
   - 已答题在答题卡上标记绿色，当前题蓝色边框高亮
   - 倒计时持续显示，<10分钟黄色警告、<5分钟红色警告
3. **提交试卷**（批量处理）：
   - 提交本科目试卷→确认弹窗→自动进入下一科目或显示总成绩
   - 未答题目按错误处理
   - 使用批量操作（batch_update_wrong_and_stats）一次性更新错题库和统计数据
4. **成绩计算**：每科独立计分，按题型权重计算，显示分科目正确率、得分
5. **错题回顾**：显示全部错题，可展开查看完整题目、选项（含颜色标记）、正确答案和解析

### 2.5 巩固练习模块

#### 2.5.1 功能描述
独立模块（与错题本并列），专注于**掌握不牢靠**和**遗忘预警**的题目。从知识掌握情况分析中筛选出不稳固（掌握不牢 + 遗忘预警）的题目，按优先级排序抽取60题进行集中训练。采用统一提交模式，提交后展示正确题目回顾和错题复盘双重反馈。

#### 2.5.2 出题优先级（三层排序）

| 优先级 | 条件 | 说明 |
|--------|------|------|
| tier0 | 处于"遗忘预警"列表 | 最优先出题 |
| tier1 | 处于"待复习"列表 | 次优先出题 |
| tier2 | 处于"不稳定"列表 | 补充出题 |

同层级内按 `wrong_count - correct_count` 降序排列。

#### 2.5.3 交互逻辑

1. **开始练习**：选择巩固练习 → 系统自动筛选不稳固题目 → 按优先级抽取60题
2. **答题过程**：与专项训练一致的统一提交模式，答题卡导航
3. **提交成绩**：批量操作更新错题本和答题统计（含 `_data_version += 1` 触发首页缓存刷新）
4. **成绩报告**：
   - ✅ **正确题目回顾**：每道正确题可展开查看题目、选项和解析
   - ❌ **错题复盘**：每道错题展开显示题目、选项（绿色✅=正确答案、红色❌=用户错选、⬜=漏选）、用户答案与正确答案对比、解析
   - 分题型统计正确率
5. **数据更新**：成绩纳入错题本和答题统计，与其他模块联动

### 2.6 错题本模块

#### 2.6.1 功能描述
提供**错题解析**和**做错题**两种模式。错题解析模式以左右布局展示错题列表和详细解析；做错题模式从错题库中提取最多50道题进行统一提交训练。错题库以纯题号列表（qid数组）形式存储，所有统计数据从 question_stats.json 读取。

#### 2.6.2 错题判断规则

**核心规则**（v2.3）：
- 错题判定依据 `question_stats.json` 中的累计统计数据（`correct_count`/`wrong_count`），而非单独维护的 `wrong_count` 字段
- 入错题本条件：`wrong_count >= correct_count` **且** 至少答过一次（`wrong_count > 0` 或 `correct_count > 0`）
- 出错题本条件：`correct_count > wrong_count`（即答对次数严格大于答错次数）
- 从未答过的题目（`wc=0, cc=0`）不会进入错题本

#### 2.6.3 交互逻辑

1. **错题解析模式**：左侧按易错程度排序的题目列表，点击后在右侧显示完整题目、选项、正确答案和解析
2. **做错题模式**：从错题库按优先级排序抽取最多50题，统一提交答题模式
3. **我已掌握本题**：手动将某题从错题本移除（仅当 `correct_count > wrong_count` 时生效）
4. **清空错题本**：二次确认后清空所有错题记录
5. **错题统计**：所有统计数据从 `question_stats.json` 读取（易错程度按 `wrong_count - correct_count` 降序排列）

## 3. 非功能性需求

### 3.1 性能要求
- 题库加载时间不超过3秒
- 页面导航切换响应时间不超过0.5秒（v2.3 通过 session_state 缓存机制实现）
- 模拟考试倒计时精度在1秒以内
- 题库导入解析速度：单文件不超过5秒
- 所有提交操作使用批量函数：单次读取+单次写入（4次I/O以内完成）
- 首页统计：缓存命中后 0 次 I/O，首次加载 6 次 I/O

### 3.2 可靠性要求
- 考试中途意外关闭后状态不丢失（Session State 内数据仍保留）
- 数据文件定期自动备份（每日首次启动）
- 导入中断不破坏已有题库数据
- JSON文件损坏时自动重建空数据结构，不影响应用启动

### 3.3 易用性要求
- 所有交互操作有明确反馈提示（st.success/error/warning/info）
- 重要操作（提交试卷、清空错题/题库）有二次确认
- 响应式布局，适配不同屏幕尺寸
- 错题本导航栏显示错题数量角标，如 "📕 错题本 (135)"
- 答题卡使用 Streamlit 原生按钮，确保导航可靠性
- 答题卡按钮字号 CSS 缩小至 10px，确保三位数题号不换行
- 全局基础字号 18px

### 3.4 数据持久化
- 所有数据以JSON文件存储于 `E:\LingMa\exmsys\data\`
- 核心数据文件：questions.json、wrong_questions.json、question_stats.json、config.json、mock_exam_records.json、answer_records.json、study_records.json
- 每日首次启动自动备份数据文件到 `data/backup/`

## 4. 核心模块设计

### 4.1 docx题库解析器 (parser.py)

解析规则（逐行扫描docx段落）：
1. 匹配 `^(\d+)\.\s` 开头 → 题目行
2. 题目行中检测 `(单选题|多选题|判断题|不定项选择题)` → 确定题型
3. 后续段落匹配 `^[A-Z][：:]` → 选项
4. 匹配 `正确答案：` → 答案
5. 匹配 `答案解析：` → 解析
6. MD5哈希生成（题目+选项+答案），取前12位作为唯一ID

### 4.2 数据管理器 (data_manager.py)

**核心函数分类**：

**题库管理**：`load_questions()` / `save_questions()` / `dedup_import()` / `get_all_categories()`

**抽题算法**：
- `extract_questions()` — 按题型随机抽样
- `extract_questions_by_category()` — 按知识板块抽题
- `extract_questions_by_super()` — 按超类（基础理论/咨询实务）抽题
- `_priority_sample()` — 优先级排序抽题（错题优先>新题>旧题）
- `_balanced_sample_by_type()` — 均衡配额分配（确保各子板块均匀出题）

**错题管理（v2.2）**：
- `add_wrong_record(qid)` — 错题记录（基于累计统计规则判断是否入本）
- `add_correct_record(qid)` — 答对记录（基于累计统计规则判断是否出本）
- `get_top_wrong_questions(count)` — 按易错程度降序取题
- `remove_wrong_question(qid)` / `clear_all_wrong()` — 错题本管理
- `_extract_qids_from_wrong_list()` — 兼容新旧格式读取

**批量操作**：
- `batch_update_wrong_and_stats()` — 批量更新错题库和答题统计（1次读+1次写）
- `batch_add_answer_records()` — 批量追加答题过程记录（1次读+1次写）

**统计查询**：
- `get_question_stats(qid)` — 获取单题答题统计
- `update_question_stats(qid, is_correct)` — 更新答题统计

- `get_mastery_distribution()` — 知识掌握度分布分析
- `get_all_wrong_with_stats()` — 错题列表+统计合并查询

### 4.5 答案判断逻辑

```python
def check_answer(question_type, user_answer, correct_answer):
    if question_type in ("single", "judge"):
        return user_answer.strip().upper() == correct_answer.strip().upper()
    elif question_type in ("multi", "indefinite"):
        user_set = set(user_answer.strip().upper().replace(" ", ""))
        correct_set = set(correct_answer.strip().upper().replace(" ", ""))
        return user_set == correct_set  # 完全匹配才得分
```
